# Biback Das Personal Website

A responsive personal portfolio for Biback Das, built with plain HTML, CSS and JavaScript. It is ready for Netlify static deployment.

## Files

- `index.html` main website
- `style.css` design and responsive layout
- `script.js` mobile navigation
- `netlify.toml` Netlify publish configuration
- `.gitignore`

## Deploy with GitHub + Netlify

1. Create a new GitHub repository, for example `biback-das-personal-website`.
2. Upload these files to the repository root.
3. In Netlify, choose **Add new project → Import an existing project → GitHub**.
4. Select the repository.
5. Build command: leave blank.
6. Publish directory: `.`
7. Deploy.

## Before publishing

Replace `YOUR_EMAIL@example.com` and the placeholder LinkedIn/GitHub links in `index.html` with your real public links. Add a professional photo and CV later if desired.
